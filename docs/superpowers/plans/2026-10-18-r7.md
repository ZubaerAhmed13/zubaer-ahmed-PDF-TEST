# R7 product finish implementation plan

Goal: deliver v0.9.0, the final core roadmap stage, with truthful discovery/help, deliberate local controls, reviewed diagnostics and exact-build release evidence.
Architecture: extend the existing shell and guarded document navigation. Keep all 29 tool IDs, PDF engines, optional preference-only cloud sync and transient document sessions. No new services or dependencies.
Spec: R7 in the approved DocFlow World Class Roadmap (16 October 2026), reflected in this plan and docs/R7_RELEASE.md. Execute inline, followed by a fresh whole-branch code review.

## Global constraints
- English-first content in a dedicated content module, no unreviewed translations.
- No document bytes, filenames, extracted text, passwords, tokens, URLs, user agent or arbitrary logs in diagnostics. Export only explicit allowlisted booleans and validated release identity, after preview and approval.
- No automatic telemetry, new cloud operations, loss of current work or changes to processing fidelity.
- Keep physical-device, Safari offline, manual assistive-technology, authenticated cloud and moderated usability evidence separate from automated tests.

## Review focus
Sensitive data accidentally reaching reports; stale download URLs after redaction; switching tools from a nested dialog during unsaved work; storage denial and active recovery writers; unsupported search terms suggesting unsupported conversions.
