# PDF reader implementation plan

> Execute inline under the approved remaining-adapter roadmap.

**Goal:** Activate View PDF with actual selectable PDF text, direct page navigation, existing thumbnails/zoom/fit and an unchanged original download.

**Architecture:** A disposable reader module renders the pinned PDF.js TextLayer from the exact page/viewport emitted by the existing bounded canvas renderer. Cancel obsolete text-layer work when pages or zoom change and dispose it before parser teardown. Keep all source bytes unchanged. Add a labelled page-number field and explicit Go action; Enter works too.

**Spec:** Reader adapter in `docs/DELIVERY_PROGRESS.md`, reusing the proven preview engine and v2 upload/work/download structure.

- [ ] Browser regressions fail while reader is unavailable: select actual text and preserve alignment after zoom; jump across a rotated page, reject out-of-range page input, support Enter; downloaded original is byte-identical and Back recreates a single text layer.

Review focus: stale text cannot appear on a newer page; rotated/cropped viewport alignment; scanned pages honestly lack selectable text; input bounds; no changed PDF bytes; text layer and stream cancellation on Back/Forward. This slice is not OCR or a full Acrobat reader: bookmarks, clickable link annotations and cross-document search remain separate acceptance work.
